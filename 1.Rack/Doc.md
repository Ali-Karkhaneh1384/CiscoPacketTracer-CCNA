# Lab 01 - Basic Network Rack Setup

This is my first Cisco Packet Tracer lab, created as part of my CCNA learning journey.

## 📝 Lab Overview

In this lab, I practiced building a basic network rack and organizing network equipment in a structured way.

The rack includes a power distribution device, patch panel, and network switch. End devices are also connected to the switch to create a simple network topology.

## 🧰 Devices & Equipment

- 1x Network Rack
- 1x Power Distribution Device (PDU)
- 1x Patch Panel
- 1x Cisco Catalyst 2960 Switch
- 1x PC
- 1x Laptop
- Ethernet cables

## 🎯 Objectives

The main objectives of this lab were:

- Get familiar with Cisco Packet Tracer
- Learn the basic structure of a network rack
- Understand the purpose of a Power Distribution Device (PDU)
- Understand the role of a Patch Panel
- Install and organize network equipment inside a rack
- Connect the patch panel to the network switch
- Connect end devices to the switch
- Practice building a basic physical network topology
